# 📊 محلل الأسواق — Market Analyst

> منصة تحليل متعددة المحركات للذهب والعملات والأسهم والمؤشرات، بدرجة ثقة رقمية
> **شفافة وقابلة للتدقيق** — بلا ذكاء اصطناعي يخمّن، وبلا اشتراكات بيانات مدفوعة.

---

## المبدأ الذي بُني عليه كل شيء

> **لا يوجد نظام يضمن نسبة نجاح ثابتة.** أي backtest ممتاز على بيانات تاريخية
> غالباً overfitting ولا يتكرر live.

الهدف ليس التنبؤ، بل **قياس جودة الإعداد** عبر توافق مدارس تحليل مستقلة، ثم
قياس النظام لنفسه على نتائج حقيقية مسجّلة مسبقاً. ولذلك:

- ❌ لا وعود بدقة · ❌ لا تنفيذ تلقائي للصفقات · ❌ لا صندوق أسود
- ✅ كل رقم قابل لإعادة الاشتقاق يدوياً من `docs/SCORING.md`
- ✅ كل إشارة تُسجَّل بمستوياتها **قبل** معرفة النتيجة

## التشغيل خلال دقيقتين

**ويندوز:** انقر نقراً مزدوجاً على **`run-demo.bat`** — بلا إنترنت وبلا مفاتيح.
للتشغيل الحقيقي: **`run.bat`** ثم افتح <http://127.0.0.1:8000>.

**macOS / Linux:**
```bash
./run.sh                       # يجهّز البيئة ويشغّل اللوحة
```

**يدوياً:**
```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/analyst analyze --offline     # تجربة فورية
.venv/bin/analyst serve                 # اللوحة + الجدولة
```

## المحركات التسعة

| المحرك | ماذا يقرأ | يعمل على |
|---|---|---|
| **الاتجاه متعدد الفريمات** | EMA 20/50/200 · الميل · إيشيموكو · بنية HH/HL | الكل |
| **ICT / SMC** | سحب سيولة · BOS/CHoCH · Order Blocks · FVG · Premium/Discount | الكل |
| **التحليل الكلاسيكي** | دعم/مقاومة بالتجميع · قناة انحدار · فيبوناتشي · كسر وإعادة اختبار | الكل |
| **المؤشرات الفنية** | RSI · MACD · بولنجر · ستوكاستك · دايفرجنس — **تُقرأ حسب نظام السوق** | الكل |
| **الكلي والترابط** | **العائد الحقيقي 10س** · الدولار · التضخم المتوقع · VIX (من FRED) | ذهب وعملات وأسهم |
| **تموضع المضاربين** | تقرير COT الأسبوعي من CFTC · التطرف كإشارة معاكسة | ذهب وعملات ومؤشرات |
| **الحجم والموسمية** | Wyckoff: الجهد مقابل النتيجة · موسمية شهرية محسوبة من التاريخ | حيث توجد أحجام حقيقية |
| **التحليل الأساسي** | التقييم · الربحية · النمو · المديونية · التوزيعات | الأسهم فقط |
| **الأخبار والتقويم** | NFP · CPI · FOMC — **لا يصوّت على الاتجاه**، بوابة ومُعدِّل فقط | الكل |

## معادلة الثقة (الملخص)

```
w_eff(i) = وزن_أساس × مضاعف_نظام_السوق × مضاعف_فئة_الأصل × جودة_المحرك
S        = Σ(w_eff × اتجاه × قوة) / Σ w_eff                    ∈ [-1, +1]
D        = التباين المرجّح حول S                                ∈ [0, 1]
C        = 1 − λ·D                                              (التماسك)
K        = L(|S|)                                               (معايرة لوجستية)
الثقة    = K × C × مُعدِّل_الأخبار × جودة_البيانات × ملاءمة_النظام
```

كل عامل بعد `K` مضاعف في (0, 1] — **لا شيء يرفع الثقة، والنظام قادر على تخفيض
تقديره لنفسه فقط.**

**التصنيف:** `A+ ≥ 80%` · `A ≥ 70%` · `B ≥ 60%` · `C ≥ 45%` · وإلا `NO_TRADE`
— **بشرط** 3 محركات فعّالة على الأقل وتغطية ≥ 50% من الوزن المتاح.

📖 التفاصيل الكاملة والمعايرة التجريبية: [`docs/SCORING.md`](docs/SCORING.md)

## البوابات الصلبة

بوابة واحدة ساقطة تُلغي الصفقة **مهما ارتفعت الثقة**. وحالة "لم تُقيَّم" ليست
نجاحاً — إن تعذّر تحميل التقويم، فبوابة الأخبار لم تُجتَز.

جودة البيانات · توافق الفريمين الأعلى · حد الثقة · العائد للمخاطرة · حظر
الأخبار · تغطية المحركات · حظر الأرباح · قابلية التنفيذ (بيع على المكشوف) ·
نطاق التقلب — كلها في [`config/gates.yaml`](config/gates.yaml).

## قياس الأداء الحقيقي

```bash
analyst stats
```

يقرأ فقط من إشارات سُجّلت بمستوياتها قبل معرفة النتيجة، ويطبّق ثلاث قواعد:

1. **لا نسبة إصابة قبل 30 صفقة محسومة** — النسبة على عشر صفقات ضجيج.
2. **الوقف له الأولوية داخل الشمعة الواحدة** — بلا بيانات لحظية لا يمكن معرفة
   الأسبق، وافتراض الأفضل هو تماماً كيف تصنع الـ backtests أرباحاً وهمية.
3. **التوقّع بالـ R قبل نسبة الإصابة** — 40% عند 3R تتفوّق على 70% عند 0.5R.

مع مجال ثقة Wilson على كل نسبة.

## ما هو خارج النطاق عمداً

- **التنفيذ التلقائي للصفقات** — مؤجّل حتى تتراكم أشهر من نتائج التتبّع الفعلي
- **نماذج ML للتنبؤ** — لا تُبرَّر على عيّنة بهذا الحجم، وتحوّل النظام لصندوق أسود
- **موجات إليوت والنماذج السعرية المعقّدة** — لا يمكن كشفها آلياً بدقة تبرّر وزناً
